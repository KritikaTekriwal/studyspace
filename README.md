# StudySpace

A personal academic workspace where every subject gets its own organised room for materials, links, PYQs and syllabus progress.

**Live demo:** https://kritikatekriwal.github.io/studyspace/

## Features
- Subject dashboard with resource count, syllabus completion % and pending topics on every card
- Upload and open PDFs, PPTs and notes for each subject
- Save useful links (YouTube, websites, AI chats) with names
- Separate PYQ section for previous year question papers
- Syllabus tracker: units, subtopics, tick-off checklist, per-unit and overall progress bars
- Delete subjects, units and subtopics

## Tech used
- HTML, CSS, vanilla JavaScript (no frameworks)
- IndexedDB for storing uploaded files in the browser
- localStorage for subjects, links and syllabus data
- Hosted on GitHub Pages

## Note
All data is stored in your own browser, so it stays private but is not shared across devices.
